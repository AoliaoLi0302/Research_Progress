PERSONAL GOOGLE DRIVE INTEGRATION

rclone

This application is a personal Google OAuth integration operated by AoliaoLi0302. It uses the open-source rclone tool to upload research experiment progress files to the operator’s Google Drive, so that the operator can read those updates through Dots.

How it works

  1. The operator authorizes rclone to access their Google Drive.
  2. rclone uploads selected experiment status files, summaries, and reports from the operator’s computer or server.
  3. Dots reads those files through its separately configured access to Google Drive.

This integration is intended only for the operator’s own use. It is not a public sign-up service. This website provides application information and policies; it does not handle Google sign-in, upload research files, or receive OAuth credentials.

Google Drive access

Actual access is determined by the scopes shown on Google’s consent screen and the rclone configuration. Some rclone configurations request broader Drive access than the specific progress folder used by this workflow. The intended use remains synchronization of selected research progress files.

About this integration

This is a personal configuration of rclone, not the official rclone website and not a service operated by Google or Dots. See the Privacy Policy and Terms of Use.
