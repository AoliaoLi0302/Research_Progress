Privacy Policy

This policy describes the personal Google OAuth application named rclone, operated by AoliaoLi0302. Contact: lyc000302@gmail.com.

Purpose and data accessed

The integration uploads selected research experiment progress files, including status information, summaries, and reports, to the operator’s Google Drive for personal monitoring through Dots. Depending on the granted Google OAuth scopes and commands used, rclone can access Drive file contents and metadata, such as file names, identifiers, folder structure, modification times, and sizes, and can create, update, or delete files where authorized.

The precise permission boundary is the authorization shown by Google and the configured OAuth scopes. Restricting a command to a folder does not necessarily restrict the OAuth token to that folder. This policy does not claim folder-only authorization.

Use and disclosure

Google Drive data is used for the operator’s personal progress-file synchronization workflow. It is not sold, used for advertising, or used to train generalized AI or machine-learning models by this personal integration.

Files are transmitted to Google Drive. Dots is a separate service that the operator intends to authorize to read the uploaded files. Any access, retention, or other processing performed by Dots is subject to its own configuration and policies; this policy does not describe or guarantee Dots’ practices. Files may be accessible to others if the operator separately changes their Drive sharing permissions.

Storage and retention

Uploaded files remain in the operator’s Google Drive until deleted by the operator or by a configured synchronization command. Source files, operational logs, and any configured caches may remain on the operator’s computer or server until removed. rclone typically stores OAuth tokens in its configuration on the computer or server running it, enabling continued authorized access without repeated sign-in. Exact storage locations and retention depend on the operator’s configuration.

Security and website hosting

Google API communication uses HTTPS. The operator is responsible for protecting the computer or server, rclone configuration, tokens, and any local file copies. Tokens and research files should not be uploaded to the public GitHub Pages repository.

This information website has no application login form, tracking scripts, or application database. It is hosted through GitHub Pages, and GitHub may process ordinary connection information under its Privacy Statement.

Revocation and deletion

The operator can stop synchronization and revoke this application’s access through Google Account connections. Revoking authorization stops future authorized API access but does not delete existing files or local copies. To remove data, delete the relevant files from Google Drive and empty the trash as appropriate, remove local files, caches, logs, and stored credentials, and separately manage any copies or permissions held by Dots.

Google API user data

This integration’s use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

Changes and contact

This policy may be updated when the personal workflow changes. Questions or deletion requests can be sent to lyc000302@gmail.com.
